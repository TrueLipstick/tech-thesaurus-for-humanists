## Tech Thesaurus for Humanists
___TL;DR:___ _Technology isn't hard to understand. It's just badly explained._

__Tech Thesaurus for Humanists (TTfH)__ is a living glossary that makes technical concepts legible to anyone who came to technology by necessity rather than by nature.

Without condescension; without sacrificing precision.
#### Versioning
Each release is a standalone, stable Markdown file. __The current version is TTfH-1.0.md__. Future versions will be added alongside it, so the repository serves as a complete version archive.

The __scratchpad__ section at the bottom of each file collects entries under development for the next release. Everything above the scratchpad line is considered stable.
#### Suggestions
Suggestions for __new terms or improved analogies__ are welcome via GitHub Issues. No technical knowledge required to open one: just describe the term that confused you and why.
#### Local use
TTfH is deliberately built for __local adaptation__. Download the Markdown file, point your favorite local AI model at the scratchpad section, and maintain your own version at your own pace. Lurkers, drive-by readers, and anyone who grabs a copy and disappears into the woods with it: all equally welcome.
